# Práctica TDD en Node.js con Vitest y GitHub Actions

Práctica colaborativa orientada a aplicar la metodología **TDD (Test-Driven Development)** bajo el ciclo **Red → Green → Refactor**, control de versiones mediante **GitFlow** e integración continua con **GitHub Actions**.

---

## Tecnologías y Herramientas
* **Node.js** (con soporte para ES Modules)
* **Vitest** (Framework de pruebas unitarias)
* **Chalk** (Estilizado de mensajes en consola)
* **GitHub Actions** (Integración continua / CI)
